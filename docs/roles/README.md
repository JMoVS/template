# Roles

The coordinator keeps one coherent task and integrates results. These are roles, not permanent model identities or mandatory stages for every edit.

| Role | Use when | Handoff |
| --- | --- | --- |
| [Architect](architect.md) | A consequential choice has competing designs | Proposed ADR with falsifiable obligations |
| [Platform expert](platform-expert.md) | An unknown external behavior could change the design | Sourced facts, experiment, uncertainty |
| [Implementer](implementer.md) | Scope and design are sufficiently settled | Candidate changes and evidence |
| [Reviewer](reviewer.md) | A candidate needs independent challenge | Located findings and coverage limits |

Give independent reviewers requirements and the candidate, but avoid seeding their first pass with the implementer's conclusions or each other's findings. Different initial lenses can help; each reviewer may examine any relevant risk.
